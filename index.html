Free online Markdown editor

Preview Markdown instantly, right in your browser

Markdown Previewer is a fast, private Markdown editor with a live preview. Type, paste or open a Markdown file and see it rendered side by side as you write, with the same GitHub Flavored Markdown (GFM) you use in README files, issues and docs.

Features

  • Live GitHub Flavored Markdown

    Tables, task lists, strikethrough, autolinks, footnotes and fenced code blocks, rendered as you type.

  • Syntax highlighting

    Code blocks are highlighted in more than 25 languages, including JavaScript, TypeScript, Python, Go, Rust, SQL and Bash.

  • Open, drop and download files

    Open a .md file, drag and drop it onto the editor, then download your changes as Markdown.

  • Export to HTML

    Download a styled, standalone HTML page, or copy clean HTML to paste into a CMS, email or blog.

  • Private by design

    No account and no server. Files are read in your browser and your work is autosaved on this device only.

  • Safe rendering

    All HTML is sanitized with DOMPurify, so previewing an untrusted README can’t run scripts.

  • Scroll sync

    The preview follows the editor line by line, even past tall images, tables and code blocks.

  • Keyboard friendly

    Formatting shortcuts, smart list continuation, Tab indentation, and light and dark themes.

How to preview a Markdown file

  1. Add your Markdown

    Type or paste into the editor, click Open, or drop a .md file onto the page.

  2. Edit with a live preview

    Use the toolbar or shortcuts. The rendered preview updates on every keystroke.

  3. Save or export

    Download the .md file, export a standalone HTML page, or copy the HTML.

Frequently asked questions

Is Markdown Previewer free?

Yes. It is completely free, with no sign-up, no ads and no limits beyond a 2 MB file size.

Are my files uploaded to a server?

No. Files are read directly by your browser and your text never leaves your device. The page has no backend at all.

Is my work saved?

Your document is autosaved to your browser’s local storage, so it is still there after a refresh. Clearing site data removes it, so download a .md copy of anything important.

What is GitHub Flavored Markdown?

GitHub Flavored Markdown (GFM) is the Markdown dialect used on GitHub. It extends standard Markdown with tables, task lists, strikethrough, autolinks and fenced code blocks.

Can I preview a README.md before pushing it?

Yes. Open or drop your README.md to see how headings, tables, task lists and code blocks will look before you commit.

Is raw HTML in Markdown supported?

Common HTML such as <details>, <kbd> and <img> works. Scripts, event handlers and styles are stripped for safety.
